One line, 123 characters: an AI agent given one job and 200,000 tokens of context spends 199,999 reading the job and uses the last token to forget it. The program writes the line to `entry.txt`, honouring `MAKEFUN_OUTPUT_DIR` first, then `/output`, then a local fallback.

## Run it

```sh
python3 main.py
```
